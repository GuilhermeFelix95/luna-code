# Luna Code

Harness desktop para conectar vários CLIs de agentes e contas de provedores sem perder contexto. Licença Apache-2.0.

Estado atual: esqueleto do monorepo com uma janela Electron. Os passos seguintes estão no plano de cada branch.

## Requisitos

- Node 24.x
- pnpm 12.15.0

## Início rápido

```sh
pnpm install
pnpm --filter @luna-code/desktop start
```

Comandos completos estão no `CLAUDE.md`.
